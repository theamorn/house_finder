# Feature request: saved searches

**From:** Ploy (Product)
**Date:** 2026-08-03
**Priority:** "high"

---

Hi team,

Users keep telling support that they set up the same filters every time they
open the app. Somebody in the Line group called it "re-doing my homework every
morning".

Can we let them save a search? So they set their filters once and then just tap
it next time. And ideally tell them when something new matches — a few of the
serious buyers said they'd check the app more often if it did that.

Sales also want this because agents keep asking which searches are popular.

Not sure how hard this is. Can we get it in the next release?

Thanks,
Ploy

---

*(Workshop note: this request is deliberately underspecified. It is the input
for the brainstorm → research → spec lab. Roughly six real decisions are
hiding in it — where searches are stored, whether "tell them" means push or
in-app, what counts as "new", whether sales analytics is in scope at all, what
happens to a saved search when filters change shape, and how many a user can
have.)*
